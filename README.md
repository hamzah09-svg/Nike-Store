# Nike Store Landing Page

A responsive Nike-style store landing page built with **HTML and CSS only**. I made it as a practice project to strengthen my front-end fundamentals.

> This is a learning project .

**Live demo:** https://hamzah09-svg.github.io/Nike-Store/

## Features

- Sticky navigation bar with a frosted-glass effect and hover underline animations
- Announcement bar at the top of the page
- Full-width hero section with an image overlay and call-to-action buttons
- "Shop by Category" tiles for Men, Women and Kids
- Featured products grid with sale/new badges, hover lift and image zoom
- Promo banner and a "Why shop with us" feature strip
- Multi-column footer
- Fully responsive layout for desktop, tablet and mobile

## Built With

- HTML5
- CSS3 (Flexbox, Grid, media queries, `position: sticky`, `position: absolute`, transitions, gradients)

## What I Practised

- Structuring a page with semantic HTML
- Building layouts with Flexbox and CSS Grid
- Positioning elements with `relative`, `absolute` and `sticky`
- Writing responsive designs with media queries
- Adding hover effects and transitions
- Using Git and GitHub to publish a project

1. Clone the repository:
```bash

```
2. Open the folder and double-click `index.html` to view it in your browser.
